# 指标口径 v2（2026-11-20 更新）

本文件是项目唯一的指标定义来源。报告、看板、README 里出现的数字都必须能在这里找到口径。

## 1. 两个分母，永不混用

| 指标 | 公式 | 分母 | 用来说明什么 |
| --- | --- | --- | --- |
| 商品点击率 item_ctr | 点击商品数 / 曝光商品数 | 商品曝光 | 单条结果被点的概率，受结果条数强烈影响 |
| 搜索请求点击率 request_click_rate | 有点击的请求数 / 请求数 | 搜索请求 | 用户这次搜索有没有被满足（至少点一次） |
| 样本购买请求率 request_purchase_rate | 有购买的请求数 / 请求数 | 搜索请求 | 购买意图是否被承接，不等于订单转化率 |
| 商品购买率 item_purchase_rate | 购买商品数 / 曝光商品数 | 商品曝光 | 仅作辅助，购买标签不等于支付订单 |
| 低曝光请求占比 | 曝光 < 5 条的请求数 / 请求数 | 搜索请求 | 替代“零结果率”的护栏指标 |

> 为什么不能用“下单率/支付率”：数据没有订单、支付、金额字段，购买只是同一次搜索里的商品标签，且 1,438 个购买商品不在同次点击列表中（2.82%），不能当严格漏斗。

## 2. 结果条数分层（本版核心修正）

v1 直接用全样本 CTR 当基准，会把“结果给得多”误判成“承接差”。实测结果条数对单件点击率的影响是决定性的（train）：

| 每次展示条数 | 请求数 | 曝光数 | 商品点击率 | 请求点击率 |
| --- | --- | --- | --- | --- |
| 1–10 | 239,311 | 1,274,905 | 8.96% | 36.6% |
| 11–20 | 92,917 | 1,392,891 | 6.97% | 57.4% |
| 21–30 | 54,061 | 1,359,819 | 5.32% | 62.1% |
| 31–40 | 34,969 | 1,231,183 | 4.43% | 65.5% |
| 41–60 | 42,226 | 2,088,289 | 3.78% | 69.2% |
| 61–100 | 38,513 | 2,977,031 | 3.11% | 74.4% |
| 100+ | 37,015 | 6,982,515 | 2.19% | 84.1% |

**口径定义**

```
期望点击 = Σ(该查询在各条数段的曝光数 × 该段的训练段基准 CTR)
期望 CTR = 期望点击 / 该查询总曝光
残差 gap_pp = (期望 CTR − 实际 CTR) × 100
机会量 gap_clicks = 期望点击 − 实际点击
```

- 基准 CTR 只用 **train** 估计，test 只做方向复核。
- `gap_clicks` 是**描述性差距**，不是可回收点击、不是收益预估。
- 条数分层与“列表位置”是两件事：位置效应在长列表内部只体现为尾部衰减（41 位以后），主要差异来自条数，所以本版不把位置当主变量。

## 3. 搜索需求标签（规则化，可替换）

`config/intent_rules.csv` 定义四类信号：店铺/品牌、属性/型号、场景/人群、品类名词。一个 query 可命中多类，按以下顺序取主标签：

1. 品牌/店铺词
2. 品类+修饰词（品类 + 属性/场景）
3. 纯品类词（只有品类信号）
4. 属性/场景词（无品类）
5. 无品类信号

**这不是机器学习分类器**，是可审计的规则。`outputs/intent_review_sample.csv` 抽 200 条供人工复核，复核结果决定是否调整规则；报告里所有意图结论都必须注明“规则标签”。

## 4. 机会表与统计

筛选条件（train）：请求 ≥ 100、用户 ≥ 30、曝光 ≥ 1,000、`gap_clicks > 0`。

- `wilson_low/high`：商品点击率的 95% Wilson 区间。
- `p_value`：观测点击数相对“同条数段期望率”的双侧正态近似检验；期望率被当作已知常数，因此偏乐观，仅用于筛查。
- `q_value`：对全部候选做 Benjamini–Hochberg 校正。
- `validation`：test 曝光 < 100 记“验证样本不足”；否则比较 test 商品点击率与 test 整体，标“后段方向一致/未复现”。

⚠️ 样本量大时 p 值会极小（本项目 Top 候选 p 可到 1e-50），**不要用 p 值当重要性**，看 `gap_pp`、`gap_clicks` 和置信区间宽度。

## 5. 护栏指标

| 动作 | 主指标 | 护栏 |
| --- | --- | --- |
| 泛品类词结果页改版 | 商品点击率（同条数段比较） | 请求点击率、购买请求率、低曝光请求占比、商品覆盖量 |
| 搜索词治理/同义词 | 目标词的商品点击率 | 购买请求率、无结果/低曝光占比 |
| 商品信息补全 | 目标商品/类目的点击率 | 类目整体购买率、退货相关指标（数据外） |

## 6. 明确不做的推断

- 不做“曝光 → 点击 → 购买”的严格漏斗图（1,438 个购买不在点击列表）。
- 不把 `time_index` 还原成日期/小时/星期，不做“周末效应”“分时运营”。
- 不把 Lite 样本的点击率当作平台真实水平。
- 不声称任何运营动作带来真实提升（无线上实验）。
