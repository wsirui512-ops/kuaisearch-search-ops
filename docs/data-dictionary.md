# 数据字典与质量审计

来源：KuaiSearch-Lite（官方 Hugging Face 数据集，版本 `16f555af360f6a86209f60eb1f12462f9e25be2c`）。
下载与 SHA-256 校验见 `scripts/download_data.py` 与 `data/raw/kuaisearch/source_manifest.json`。

## 1. 文件与规模

| 文件 | 行数 | 大小 | 内容 |
| --- | --- | --- | --- |
| `recall_lite/train.jsonl` | 555,553 | 258 MB | 搜索请求：用户、会话、曝光/点击/购买商品列表、相对时间、查询词、split |
| `items_lite/train.jsonl` | 5,548,777 | 2.79 GB | 商品：标题、品牌、商家、三级类目 |
| `users_lite/train.jsonl` | 102,086 | 13 MB | 用户：性别、年龄段、国家/省/市 |
| `relevance/train.jsonl` | 46,422 | 15.8 MB | query–商品标题相关性标注（score 0–3） |

> 一条 `recall_lite` 记录 = **一次搜索请求**，不是一个商品曝光。曝光粒度由 `impressed_item_ids` 展开得到，共 17,800,904 行。

## 2. 字段说明

### 2.1 搜索请求 `recall_lite`

| 字段 | 类型 | 说明 | 项目中如何使用 |
| --- | --- | --- | --- |
| `user_id` | int | 用户 ID | 去重用户、年龄关联 |
| `session_id` | int | 请求 ID，全表唯一 | 请求级主键 |
| `query` | string | 搜索词，中文，无空值 | 需求标签、query 维度指标 |
| `impressed_item_ids` | int[] | 召回列表，**有序**，是展示顺序 | 曝光、位置、结果条数 |
| `clicked_item_ids` | int[] | 本次请求内被点击的商品 | 点击 |
| `purchased_item_ids` | int[] | 本次请求内被购买的商品标签 | 购买标签（≠订单） |
| `time_index` | int | 相对时间索引，1–965,265 | 只做相对区间，不还原日期 |
| `split` | string | `train` / `test` | 时间切分，见下 |

### 2.2 商品 `items_lite`

`item_id`、`item_title`、`brand_id`、`brand_name`、`seller_id`、`seller_name`、`category_level1_id/name`、`category_level2_id/name`、`category_level3_id/name`。

- 商品表只保留被曝光过的商品（5,548,777 个），全部能匹配上曝光，缺失为 0。
- `category_level3` 大量为 `UNKNOWN`，因此分析只用一级/二级类目。
- 商品标题与属性可用于“承接质量”人工审阅，但没有结构化属性字段。

### 2.3 用户 `users_lite`

`user_id`、`gender`、`age_bucket`、`fre_country`、`fre_province`、`fre_city`。

⚠️ 年龄段分布异常：12–17 岁占训练段请求的 17.1%，0–11 岁仍有 2,329 次请求。这更像默认值或粗略分桶，**报告只做结构描述，不做人群运营结论**。

### 2.4 相关性标注 `relevance`

`query`、`item_title`、`brand`、`seller_name`、`attr_value`、`score`（0–3）、`split`。

- 共 46,422 对，覆盖 46,325 个 query，其中 46,228 个 query 只有 1 对。
- 没有 `item_id`，无法直接关联到曝光商品；只能按标题/查询词做抽样佐证。
- 本项目**不做**聚合相关性分析，只在报告里说明覆盖不足（例如"鞋子"0 对、"手机壳"1 对）。

## 2.5 采样口径

官方未公开 Lite 的抽样比例与随机方式（是否按用户、按请求或按时间抽样均无说明）。本项目只按记录自带的 `split` 做时间切分，不重新抽样；因此所有比例、缺口与排名都只描述这份样本，不能外推为平台整体。

## 4. 关键结构事实

- 去重 query：278,615 个；平均每个 query 约 1.9 次请求。
- 每次请求展示条数：均值 32.1，中位数远低于均值，最大值 2,196 —— 分布右偏严重。
- **6.9% 的请求展示了 100 条以上商品，却贡献了 40.3% 的商品曝光**。
- train 时间范围 1–936,724，test 936,726–965,265：test 严格晚于 train，是**时间外切分**，不是随机留出。
- 曝光商品与点击/购买的商品列表均为去重集合，不含商品排序分、价格、广告位。

## 5. 已知限制（会写进报告）

1. Lite 为采样数据，绝对值不代表快手电商全站。
2. 没有价格、订单、金额、广告位、曝光位置（仅列表顺序）。
3. `time_index` 为相对值，无法做日期/小时/星期分析。
4. 购买标签不等于支付订单，不能计算 GMV 或真实转化率。
5. 年龄、性别、地区字段质量未知，不做人群结论。
6. 相关性标注覆盖极低，不能支撑“相关性差导致低点击”的定量结论。
