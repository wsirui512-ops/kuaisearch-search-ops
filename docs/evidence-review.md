# 承接证据审阅：方法、模板与结论边界

## 1. 为什么要做这一步

机会表只能证明"这些搜索词在同条数条件下点击偏少"，**不能证明原因**。原因至少有四类：

1. 商品标题/属性与查询不匹配（信息没写清楚）；
2. 类目放错，用户看到一堆不想买的东西；
3. 排序问题，好商品在很后面；
4. 需求本身宽泛，用户只是逛（点击低是正常的）。

人工审阅的作用：把"可能的原因"逐条标出来，让动作有依据，而不是凭感觉。

## 2. 已生成的审阅表

`outputs/review_table.csv`（本地，含商品标题，不发布）：

| 列 | 含义 |
| --- | --- |
| `rank` / `query` | 机会排名与搜索词 |
| `item_rank` | 该词下按曝光量排序的商品序号（1 = 曝光最多） |
| `item_title` / `brand_name` / `category_level1/2` | 商品信息 |
| `exposures` / `clicks` / `purchases` / `item_ctr` | 该商品的曝光、点击、购买与点击率 |
| `avg_position` | 该商品在召回列表中的平均位置（1 = 最靠前） |
| `bigram_coverage` | 自动预筛：query 的二字片段在标题中出现的比例 |
| `query_in_title` | 标题是否完整包含 query |
| `human_relevance` / `human_note` | 预留字段，自动预筛不填写 |

生成命令：`python scripts/build_review.py`。人工抽检另用 `python scripts/make_spotcheck.py` 生成空白 30 行工作簿。

### 2.1 用工作簿审阅（推荐）

`outputs/spotcheck_30.xlsx` 是可填写的 30 行工作簿，打开即可用：

| Sheet | 内容 |
| --- | --- |
| 说明 | 判读规则、填写口径、预计耗时（20 分钟） |
| 抽检表 | 30 行明细，判断与理由留空；每词按曝光量取第 1、5、10 名 |

生成命令：`python scripts/make_spotcheck.py`（需要 openpyxl，含标题，仅本地）。填完后运行 `python scripts/apply_spotcheck.py`。

**词级汇总里的四个自动证据怎么用**

| 字段 | 读法 | 指向的动作 |
| --- | --- | --- |
| `distinct_category1` / `top1_category_share` | 高曝光商品是否集中在单一类目 | 集中 → 查类目承载；分散 → 查意图拆分 |
| `top1_brand_share` | 是否被少数品牌/同款占满 | 高 → 可能铺货，查标题信息质量 |
| `avg_attribute_types` | 标题里平均出现几类属性（季节/版型/材质/型号） | 低 → 商品信息补全 |
| `click_share_top10` | 点击与召回列表前 10 个位置的关联比例 | 不能推断用户是否滚动或实际展示位 |

## 4. 怎么读这张表（关键）

**二字覆盖率低，不等于商品不相关。**

- "衣服"的覆盖率是 0：商品标题写的是"卫衣/连衣裙/外套/衬衫"，不会写"衣服"。这是品类词的正常现象，不能据此说供给错了。
- "鞋子"覆盖 20%：标题写"小白鞋/板鞋/德训鞋/面包鞋"，同样不含"鞋子"。
- "外套""裤子""手机壳"覆盖 100%：这些词本身就出现在标题里。

所以正确用法是：**用覆盖率筛出值得逐条审阅的样本**，再判断：

- 用户的意图是不是被标题里的**具体属性**（版型、材质、场景、型号）承接？
- 类目是否分散？同一搜索词下的商品是否跨了多个不相干类目？
- 高曝光商品的点击率是否普遍很低，还是只有头部几个特别差？

## 5. 逐条审阅结果与判读规则

二字覆盖率是自动预筛，不据此判断相关性；人工抽检见本节 30 条结果（26/4/0）。`我的判断` 口径：

- `1` = 商品确实符合这个搜索意图（标题信息能支撑用户判断）
- `0` = 不符合（类目错、属性错、明显是别的需求）
- `0.5` = 相关但信息不足（例如只写"外套"没写季节/版型）

判读：

- 若某词 **≥70% 的高曝光商品为 0**，优先怀疑供给/类目问题 → 动作 C（商品信息补全 / 类目治理）。
- 若某词 **多为 0.5**，优先怀疑信息缺失 → 动作 C（标题属性补全）。
- 若某词 **多为 1 但点击仍低**，只能说明这批高曝光商品未显示明显错品类；结果页结构与需求宽泛仍是待验证假设。
- 若同一商品在高曝光下点击仍持续偏低，记录其 `item_id`，可作为动作 C 的实验对象。

## 6. 结论边界

- 审阅样本是"高曝光商品的 Top 10"，不是随机样本，**不能外推为该词的全部供给**。
- 100 行只能支撑"这个方向值得查"，不能支撑"X% 的商品不相关"这类比例结论。
- 要写比例结论，至少需要按曝光分层随机抽 300–500 行，并记录抽样方法。
